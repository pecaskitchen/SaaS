# Pecas

Recursos versionados exclusivos del tenant Pecas.

- `catalog/`: catálogo base utilizado como respaldo.
- `templates/`: plantillas CSV para inventario, recetas y familias.
- Los recursos web se publican desde `public/tenants/pecas/`.
- Los pedidos, clientes, inventario y futuras transacciones de Pecas Club se
  almacenan en la base compartida de Omdexa con el `tenant_id` de Pecas.
